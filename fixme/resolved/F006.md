    gate       test/test_precommit.py::test_a_fixtures_git_add_never_reaches_the_index_git_handed_the_hook — a pytest run over a scratch test that adds in its own repository, with `GIT_INDEX_FILE` set to a stray absolute path the way the hook sees it; the stray must never come to exist
    see        test/conftest.py (the fixture rule: the suite builds every git tree it means, and none of them is the person's), tools/pre-commit.sh, F005 (the commit that was refused twice)

The fixture rule already covered the config and the identity; the index
is one more face of it.  `test/conftest.py`'s git fixture now drops
`GIT_INDEX_FILE`, `GIT_DIR`, `GIT_WORK_TREE`, `GIT_OBJECT_DIRECTORY` and
`GIT_COMMON_DIR` for every test, so a fixture's git can only reach the
repository the fixture built.  Nothing in the hook changed: git's
protocol is git's, and the suite is not a git operation.

What this was not: the tree's index was never touched — the temporary
index died with the refused commit — and no earlier commit carried a
scratch file (checked: the three before, `--stat`).  The cost was one
refused commit and the hour that found it.
