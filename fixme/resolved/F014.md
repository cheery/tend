## What it costs

One question to a session per failed turn, and the wrong repair when
nobody asks: the same sentence for "the node is down" and "the key is
wrong" and "the door's side timed out at 600 s" invites the fix for
whichever the reader guesses first.  On 2026-09-02 the guess would have
been the key file or `--jinja`, both of which were in place; the cause
was a runner that had idled out three days earlier.

## The fix's shape, not taken yet

Print curl's last stderr line from `$_raw` after the door's sentence,
before the file is removed — the reason travels one line further and
nothing else changes.  The node's branch gets the same line, so "is it
up?" becomes "Connection refused" when that is what it was.  The HTTP
refusal path at `:194` already shows the form: one line, its code and
its words, never the body.
