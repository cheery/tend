## The fix

Two changes to the test and none to the tree: serve's report is waited
for like the status line above it (it is late by one window, not
absent), and the test holds the edge itself — a shared `flock` on
`pulled/solitaire` taken once the puller's own hold is seen — while it
reads `status`, so the pulled state stands still under a 400 ms read;
it lets go before asserting the edge was let go and the die idled out.
The claim `status` names the puller is kept, and is now read from a
state that cannot end mid-read.  Gate: the flow test itself, run alone
and shaken — a fixture of "the flow is faster than the read" would be
this test before the change, which is on the ledger seventeen times.
