## The second face, 13:33–13:41 — the fix's own fence touched every pull file

The first fix put `touch "$pf"` into `tools/sandbox.sh` where `: >
"$pf"` had been, because a failing redirection on a special builtin is
fatal under `set -e`.  It dropped the `[ -e "$pf" ] ||` guard with it,
so the fence **touched** every node's pull file at every command
instead of making a missing one.  The pull file's mtime against
`stopped` is `serve`'s whole rule, so the tick restarted the die at
13:35 (the tree's copy, run by `test_sandbox.py` from inside the
fence, where the pull file is the one writable bind) and, once Henri
installed that commit at 13:38, the llm node at 13:40 — the model on
the GPU on a pull nobody made, at every tick after every command.
Seen by a `last stop: 13:35:02 — idle` on a die whose only runs were
in scratch, and by `ls --time-style=full-iso` on three pull files all
stamped 13:39:50, the second of the session's last command.  Fixed at
13:41 (`3861ca9`): made only when missing, never touched, and the
gate is `test_sandbox.py::test_the_fence_makes_a_missing_pull_file_and_never_touches_one_that_exists`,
which reads the first node's pull file mtime before and after a fence
that is refused after the precreation — red against the touching
commit, green after.  Measured after his second install at 13:5x: the
mtimes stayed at 13:41:13 through a command, and the llm idled out.

Two lessons, both on the session: a fix to a guard is read for the
guard it removes, not only the line it replaces; and a change to the
fence is measured on the person's side before it is handed to him,
because his install puts it in force on the next tick.

## What it cost

Thirty seconds of a die and one death notice on the panel — nothing.
On the llm node the same meeting would be an 80 s model load and a
minute of GPU at the first tick after a fresh clone or a new state
directory, once, with the log saying "had an unserved pull" about a
pull nobody made: exactly the sentence the resolver was built not to
say (`board/done/resolver.md`, "a pull with no runner gets one" — a
pull, not a file).
