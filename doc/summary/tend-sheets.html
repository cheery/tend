What holds, and why

Sheet 1 / 2 · the rules

Fifteen invariants a session works under. Each is enforced by a mechanism in the tree, not by good intentions — the whole point is that the boundary sits where a session cannot reach it.

The boundary
R1

The enforcement boundary lives outside a session's write access, or it is decoration. vision.md · the founding line

R2

A session may not widen its own reach; the bound is the person's, set in the hook's own line. fence-hook.sh · TEND_REACH_ALLOW

R3

The scripts that enforce are read-only to the session and denied to its edit tools. sandbox.sh · the protected set

R4

A restraint must be able to say when it is off — silence is the failure it exists to end. fence.sh · at every prompt

The record
R5

A card names a problem, in the words of whoever had it — never a fix. test_board.py · refuses a card without one

R6

Every sitting ends with a kaizen — the measure is commits since the last one, not the date. kaizen.sh · the lamp

R7

Git is the only canonical copy: restore means checkout, never a second embedded copy. fence.sh --restore

R8

Every commit runs the gates first; a red gate refuses the commit, working tree unmoved. pre-commit.sh · suite.py

Honesty
R9

Errors are never silent. A sensor that cannot read a value says ?, never a wrong number. leash.sh · cpu column

R10

Measure, don't assert or borrow. A practice owes this is what it caught, that you'd have shipped. manifesto.md

R11

A mechanism a session cannot test, it proposes — it does not declare it done. doc/kaizen/ · a standing rule

R12

Nothing unexpected, silently. Loud within one prompt beats quiet and correct-looking. vision.md

The program
R13

A hang is a crash. A wall budget bounds every run; overrun is exit 124, said out loud. leash.sh · leash → sandbox → cmd

R14

A program opens where it was left, from a plain file a person can read without it. node/node.py · state

R15

A program runs while something pulls it and quits itself when nothing does. Default: off. node/node.py · pull lifecycle

Sheet 2 / 2 · interfaces

Everything human-facing, by kind: the keys only you may turn, the instruments a session and you both run, what the tree says back unbidden, the plain files you read — and the one outward cord, the andon.

Keys you hold yours · run unfenced
tools/reach-allow.sh net,audio,… Set the fence's reach bound. Writes TEND_REACH_ALLOW on the hook's line — the rows a session may ask for.
tools/hook-installer.sh Install the per-command fence. Edits .claude/settings.json; hook config is enforcement, so the edit is yours.
tools/fence.sh --protect Lock the enforcement scripts. Adds the missing deny rules and nothing else. Narrows, never widens.
These three change what a session is allowed to do. They live outside the tree, or read-only inside it, on purpose.
Instruments you run
tools/sandbox.sh --check Prove the fence is up — the sitting clock first, then the secrets. Also --rows, --protected.
tools/fence.sh Is the deny-list in force? --restore puts a lost file back from git.
tools/leash.sh -t -c -m -- cmd Run one thing under a wall / CPU / memory budget; leaves a ledger line.
tools/limit.sh Where the sitting clock stands — how long in, how long left.
tools/kaizen.sh want "why" Read the lamp, or declare a kaizen owed and carry the reason forward.
tools/toolbox.sh Set a clone up and say what a machine is missing — the stranger's first command.
node/node.py run · pull · status The first program: start it, pull it, read what it did.
What the tree says back unbidden
Every prompt — three lamps run before your words reach the session: the kaizen lamp (a sitting owes its close), the sitting clock, and the fence lamp (🔴 if the deny-list weakened).
Every command — the fence hook wraps it as leash → sandbox, or refuses a reach outside your bound with a reason.
Every commit — the gate runs the suite and refuses a red one, naming what failed and how to skip it on the record.
Plain files you read
board/ · done/ · later/ The work itself — one card per problem. You fill it; a session works it down.
~/.local/state/tend/leash.log Every budgeted run: when, how long, what it cost, whether the budget applied.
doc/kaizen/<date>-<HHMM>.md One per sitting — what went right, what went wrong named as whose, what to change.
node/*.state A program's whole memory, as JSON you can read without the program.
The andon — the outward cord card:cords.md · done 2026-08-27

The andon — tools/andon.sh: a session writes its question first (ask), then rings you through the PipeWire socket (ring — at most three, eight seconds apart, refused within ten minutes of the last, refused with nothing asked). The record — ~/.local/state/tend/andon.pending, andon.log — is what sitting N because andon is granted on, read by the hook, not the session. answered is your word, refused inside the fence. The count of guessed questions closed at zero after four days; the cord's first loop closed on 2026-08-27.
