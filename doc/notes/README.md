# doc/notes/ — the conversations a card or a rule came out of

gestate's shelf of the same name, taken here on 2026-09-22 at Henri's
"I wonder if it should be inside doc/notes/ because that's the place
for this kind of files in gestate".  A transcript is kept here when
something in the tree was distilled from it, so that the distillate
and its source are both public: a card's `because` quotes a sentence,
and the sentence's conversation is one path away.  A file here is
never edited — a card cites it by section, and a fresh clone must open
what the card quotes.

  from `~/misc` on 2026-09-22; `card:protocol.md` came out of it.
