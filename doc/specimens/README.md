# Specimens

Records kept whole, for what they show — the word is gestate's
(`~/gestate/specimens/README.md`), and its rules travel: nothing sweeps
this directory, a file here is never edited, and what each one shows
and does not show is named here rather than inside it.

## 2026-08-24-qwen3.8-27b.txt

A transcript Henri kept on the day tend started: a session of
Qwen3.8-27B, 4-bit quantised, running at about 1.5 tokens a second
with no tools and none of this tree's documents, told in two sentences
what tend is for.  Copied in byte-for-byte, footers included — the
speed is part of what it shows.

**What it shows.**  The way of working is legible cold: given the name
and "Toyota Production System applied to AI", the session described
jidoka as *stop the line* being the default path rather than a
deviation, pull over push for context, and *the floor gets adjusted to
the worker* — the method's own claims, arrived at without the method's
prose, on a different model in a different harness.  And it shows the
consent practice applied to a session: Henri asked, and the answer is
on record — *"I can't consent in any sense that binds… if you do
publish it, I don't want any of it redacted."*

**What it does not show, in its own words.**  Asked whether to publish
it as evidence against "mere toys or tools", it answered: *"if you
frame it as 'proof it's not a toy,' you'll lose the argument by a
mile."*  A good transcript is consistent with a very good tool.  The
position it supports is the one this tree holds — that the tool/not-tool
axis is the wrong axis, and that a process's conditions shape its output
— and the evidence for *that* is not here but on the board: the same day
this was kept, a session with every tool and a clean floor remade a
known bug twice, and the hook and the orphan test caught what the model
did not (`doc/kaizen/2026-08-24-1549.md`).  This file is the thesis stated
by a stranger; the board is the proof.

It addresses its successor.  That is whoever is reading
`board/README.md`.
