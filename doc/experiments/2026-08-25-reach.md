## The fence

`2026-08-25-reach-fence.sh`, beside this file: bubblewrap with user,
pid, ipc, uts, net and cgroup namespaces unshared; `/usr` and `/etc`
read-only; `/tmp` and `$HOME` empty tmpfs; this project bound writable
and the working directory; `PATH` to the project's `.venv` and the
system.  Borrowed from `~/gestate/tools/sandbox.sh`, minus the
toolchain binds tend has no use for.  It worked at the first attempt:
gestate's AppArmor profile for `bwrap` is already installed on this
machine (`/etc/apparmor.d/bwrap`), which is the one piece of setup
`~/gestate/spec/sandbox.md` says Ubuntu 24.04 needs.

The escape check was made from outside, after every run: nothing
written inside the fence's home survived it, and `git status` on the
tree was unchanged.

## What the complaints say

**One finding is sharp.**  The sitting limit is the person's clock,
and a fence that hides `~/.local/state` and `/run/user` gives a fenced
session a fresh one.  The same hiding loses the leash's ledger and
silences a kaizen want.  So the state directory is not a leak to be
closed; it is the first thing any fence in this tree must pass through,
read-write and shared with the host — or every cord and lamp tend has
is decoration the moment a session runs fenced.  This is the case
`board/fence.md` §"two halves" said belonged to this card: the
namespace fence and the person-facing pieces are one design, not two.

**The rest sort into a short list of reaches**, each with a real
caller on this machine:

| reach | who asked for it | default |
|---|---|---|
| this tree, writable | everything | on — it is the world |
| `~/.local/state/{tend,gestate}`, `/run/user/$UID` | the sitting limit, the leash ledger, the kaizen want | **must be on**, shared, rw |
| the user bus | the leash, for a cgroup budget | on when the budget is wanted; without it the leash says `plain` |
| other trees, read-only | the audit; anything cross-tree | named, one at a time |
| audio out | the andon (`card:cords.md`) | off; on for the cord |
| a display | the 2026-08-18 incident's two X servers | off; and scrub `DISPLAY` when off |
| the network | nothing in tend today | off; and it should fail as a refusal, not as DNS |

Seven words.  Henri's "leash adjustable by both parties, user's leash
bounds it" reads onto this directly: the person sets which rows may
be on at all, a session turns on fewer inside that, never more.
**Not built.**  A table with seven rows and one afternoon's evidence is
a table to show the person, not a mechanism; and the row that would be
built first is the one the sitting limit needs, which is a bind, not a
vocabulary.
