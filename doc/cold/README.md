# cold/ — the same rules as commands, and this is the control arm

**This directory is not part of how tend works.  It is a measurement
instrument, and it is a copy of tend's rules with everything removed
that makes them believable.**

`card:session-program.md`'s milestone is *gemma4 working the board, next
to gemma4 cold, and we can tell them apart*.  Henri, 2026-09-01, asked
what "cold" means and answered it himself:

> I think we should create some sort of a tree that has imperative
> commandments in it that match the stuff we have here, but written as
> commands without rationale or provenance.

That is a sharper control than the one a session proposed, which was to
strip the conditioning prose entirely.  Stripping it removes the rules
**and** the reasoning, so a difference could be either.  This removes
only the *why*, which is the thing tend actually bets on: every rule in
the real tree cites the incidents that earned it, every correction sits
beside the original, every promotion names the kaizens behind it.

**The question this arm asks: is any of that load-bearing, or would "do
X" have done the same work?**

## The rule for whoever edits this

**A commandment here carries no reason, no date, no name, no incident,
no citation, and no exception.**  If a line explains itself, it belongs
in the real tree and not here.  If a rule in the real tree cannot be
written as a command without its reason, **say so in `notes.md` rather
than smuggling the reason in** — that finding is worth more than a tidy
file, because it is the first thing this experiment could discover.

**It matches what tend has.  It does not improve on it.**  A command
here that has no counterpart in the real tree is a confound: the arms
would differ in content as well as in form, and the measurement would be
worthless.  Where the real tree is silent, this is silent.

2026-09-01 at Henri's ask so that he could read it at his own pace, and
a session writing the control arm it will be measured against is exactly
the shape the self-shaped mark exists for.*
