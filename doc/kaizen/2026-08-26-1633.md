## What the sitting was

The grant-beside model landed by Henri's hand after a fix: four
`test_keep.py` tests asserted against `node/run.sh`'s old body, which
the patch had turned into a wrapper.  Repointed — the node's `no-net`
to `node/grant`, "started a runner" to the launcher's "started node",
the grant-drift guard to `launch.sh` — and two eager waits guarded for
`node.state`, which the generic launcher writes a beat after `pull`
returns.  Then, with llama.cpp installed and the fence committed, the
second node ran the whole loop from a session's seat: run refused
(state read-only), pull recorded, resolver started `llama-server` three
times, each stopped on idle.

## What went right

**The fence closed on the second node without a line about it.**
`llm/state` read-only inside, its pull file the one write — from the
one loop in `sandbox.sh` over `*/grant`, not a rule naming llm.  Adding
the node was adding a directory, exactly as the model promised.

**The failure was read to its cause, not worked around.**  "Connection
refused" looked like a broken serve; the mtimes said the pull *was*
served and the server had idled out — a race between a 30 s load and a
60 s idle, not a defect.  Stopped racing once the ledger (the log's
three `model loaded`) proved the loop.

## What went wrong, named as the session's

**A patch moved a file's internals and I did not grep the tests for its
name.**  `test_sandbox.py` was folded into the patch; `test_keep.py`
had four tests reaching into `node/run.sh`'s body and I missed them, so
Henri's suite went red.  The countermeasure is exact: a patch that
changes what a file *is* (here, run.sh from launcher to wrapper) is
followed by `grep -rl node/run.sh test/` and every hit read, before the
patch is handed over.  I had the rule for the protected set
(`--protected | grep`) and not for this.

**I raced a live timing loop I had already named as a trap.**  Four
`curl`/query attempts against the server's idle clock, the same
seat-timing shape `green` counted at 15:12.  The ledger answers it;
the live poll does not.  One look at the mtimes would have been first,
not fifth.

## What should change tomorrow

1. A patch that changes a file's role: `grep -rl <file> test/` and read
   every hit.  Added to the patch-handoff checklist beside "`--protected`
   lists the new name" and "grep the hunk you meant to add."
2. `idle 60` vs a 30 s load is a number for the ledger, not the writing.
   Leave it; let a real session's use settle it.
3. The cords are the frame's remaining half: a node becomes a session's
   program when it carries the limit, the lamp, the andon.  The llm node
   has none.  That is the next card, and it leans on `cords` (08-31).
