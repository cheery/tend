## What the sitting was

The mediation-order frame made real.  A grant is a file beside each
program (`NODE/grant`); one launcher (`tools/launch.sh`) applies it,
holds the lock, and stops a program that cannot stop itself by watching
a pulse; one resolver serves any node by an mtime rule; the fence binds
every node's state read-only and its pull file writable, and protects
the launcher.  The node's three flags and the llm node's three lines
are two `grant` files now.  `llama-server` ran under it and answered
over loopback; the second node needed no code, only a directory.
Fourteen launcher tests, five rows; `grant-beside.patch` for the three
protected files, its test inside.

## What went right

**The measurement wrote the abstraction.**  The grant file's fields are
exactly what the two nodes needed and nothing more — three flags became
`allow/no-net/pull/program`, three lines became `allow/bind/idle/pulse/
program`.  No field was designed ahead of a node that wanted it, which
is the reach table's rule applied to a new file.

**`serve` is one rule for two programs.**  A tally has a served-count; a
server has none.  The mtime rule — a pull newer than the last stop —
needs neither, and holds for both, and is three lines.  Found by asking
what the llm node could not answer that the node could.

**The tree stayed green.**  The two new fence tests were moved into the
patch rather than left red in the tree, so the cards and this kaizen
commit without waiting on Henri's hand — last-bind's pattern, not
protect-run's.

## What went wrong, named as the session's

**A first patch had launch.sh missing from the protected set and a
test red for the wrong reason.**  My `sed` for the protected line
matched `node/run.sh"` where the line now ends `resolve.sh"`, so the
launcher never joined the set; caught because `--protected | grep
launch` returned 0, not because a test failed — the test that should
have caught it was the one I was about to write.  The countermeasure:
a patch that adds to `protected=` is verified by `--protected` listing
the new name before the patch is handed over, the same way a mutate row
is read for what it broke.

**A model URL from memory, again named.**  Carried from the 16:02
kaizen; Henri hit it this sitting ("the model URL was wrong").  The
rule is written; this is its first citation.
