## What went right

**The card was obeyed as written.**  Measure, not build: seven cheap
repairs were visible by the end, three of them one line each, and none
was made.  The card says what it must not become and the sweep card
says why a quota answers itself with tests that pass; the number is
worth more unrepaired for one day than repaired before Henri has read
it.

**The harness kept a `NOOP` column**, so a `sed` that matched nothing
could not pass as a verdict.  It never fired, and it was still the
right thing to have: the cost was one `cmp`.

**Two false verdicts were caught by arithmetic, not by trust.**  The
first gates run said `test_precommit.py: GREEN` on the row where the
hook had been uninstalled, and 16 of 19 fence tests failed on a
one-line hint removal; neither number could be right, and both were
harness bugs of mine (`$?` read after a `local`; a `sed` that left `if
… then fi`).  Rerun with failing-test names, the columns agreed with
themselves.  F88's fixture was broken before it was trusted; so was
this.

## What went wrong, named as the session's

**The harness lied twice before the numbers were read, and I only
noticed because the numbers were absurd.**  A subtler bug — one that
had made a single row wrong — would have gone into the card.  The
counter-move I did not make: run one known-red and one known-green
break through the harness *first*, as its own intact-copy check, the
way `seedmutate.sh` reads the intact copy before any mutation.  Next
harness starts with that pair.

**One sed deleted the line it had just added** (`blocked
board/nothing.md`, matched by the delete pattern `board/[a-z]`) and the
row came back GREEN for a break the test does catch.  The `NOOP`
guard did not fire because the file *had* changed.  A guard on "the
file changed" is not a guard on "the break is in the file".

**The locale broke a `sed` on the harness itself** (Finnish `sed`
error on a long substitution) and I did not see it until the names
column came back empty.  Harness edits were then done with a heredoc
rewrite, which is what they should have been from the start — the
memory `commands-for-henri-fold-in-console` is about his console, and
it applies to mine.
