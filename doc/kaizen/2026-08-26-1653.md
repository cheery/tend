# Kaizen — keep and resolver judged done, and a residual kept rather than buried

*Written because the lamp lit on the move commit.  Henri: "examine the
keep & resolver, and consider whether the conditions are satisfied for
these cards.  If they are, move them to done."*

## What the sitting was

A judgement, delegated.  Read each `because` and asked the board's own
question — does the problem still stand.  `keep`'s ("a program gets
whatever the session could reach, having been handed nothing") does
not: a program is handed a grant and reads/writes/reaches only what it
names, and the session's ambient reach was narrowed row by row to the
work tree.  `resolver`'s ("nothing starts a program but a hand; the
confinement is whatever the launcher baked in") does not: the pull is
the launch, one launcher applies the grant, a session cannot start a
node raw.  Both moved to `board/done/`, the README list renumbered.

## What went right

**The residual was measured and kept, not waved past.**  `resolver`'s
`because` ends "a session that starts a program some other way starts
it with the session's whole reach" — and that is still true: I ran
`llama-server --version` straight from the fence, unconfined by keep.
Rather than let it vanish when the card closed, it went onto
`work-environment-ai` (§16:50) and is named on `session-program` — the
session-as-principal question, which both cards had relocated it to from
day one.  A card closes when its problem is solved or *owned elsewhere*,
not when the words are simply gone.

**The judgement was the board's test, not a feeling.**  "Does the
because still stand" is the README's own line for `done/`; I applied it
to the two threads of each because separately, and named which thread
each card owned and which belonged to another.

## What went wrong, named as the session's

**Two wrong paths before the move landed.**  `git mv board/keep.md
done/keep.md` and then `mv` both failed — the shelf is `board/done/`,
not a top-level `done/`, and I wrote the path from the README's prose
(`done/grant.md`, which is relative to `board/`) without checking the
tree.  `git ls-files done/` returning empty was the tell, read on the
third try.  The countermeasure is the tree's own: a path is checked
against `git ls-files`, not typed from how prose refers to it.
