## What went right

**The location was decided by a measurement, not a preference.**  The
user-owned prefix was the obvious answer until gestate's
`.claude/settings.json` was read: no rule for `~/tend/**` or
`~/.local/**`, a fence that wraps only `pytest` and `cargo`.  So a
user-owned file is inside a gestate session's Bash reach, and
`tools/limit.sh`'s header — *"this one, a gestate session cannot
reach"* — has been aspirational since 08-24.  Root-owned
`/usr/local/lib/tend` is refused by the kernel to every uid-1000
process; `/usr` is already ro inside the fence; sudo is already denied.
Three properties, none new.

stages HEAD and never the working tree; the first smoke test ran it
before `tools/andon.sh` was committed and it refused — "HEAD has no
tools/andon.sh — commit it first."  That is the rule working, and the
tests were then written to stage from a temporary clone that commits
first, so the gate could pass on the commit that adds the script.

ring` under `strace -f -e openat,connect`: one connect to

owed that since 08-25; it cost one tone.
