## What went right

**Set-based, at the price of an hour.**  The manifesto's rule is keep
both alive and converge last; Henri's ask was the rule said out loud,
and the cost of running both was small enough that the paper argument
never had to be won.  What came back was not a winner but a
reshaping: one fence, rows on a dial, and the real question moved to
*who starts it from outside*.

**The trace, not the exit code.**  The `/dev/snd`-only ring exited 0
and said "frames through sounddevice"; a record built on that line
would have said the three nouns suffice.  Tracing it found the
hardware opened past the server and the capture device opened three
times.  Exit codes are what a program says about itself.

**A probe that reached the outside was removed on the spot.**  The
kaizen want written from inside the fence proved the bind and was
deleted in the same command, so the lamp never carried a probe as if
it were a reason.

## What went wrong, named as the session's

**Five rings for a measurement.**  The andon is designed to call
somebody who is resting, and the session rang it five times in
twenty minutes for its own evidence, saying so before each but never
asking.  Henri was active in the session, which is the only reason
that was acceptable; whether the `/dev/snd`-only ring was even
audible the session cannot know.  A cord is not a probe.

**An apostrophe in a `${:?}` message** cost a full re-run of the
programs-first trial.  `sh -n` before the first run would have caught
it; the session ran `sh -n` on the tool it wrote earlier and not on
the script it wrote later.

**The sessions-first mechanism was not tried, only its fence.**  A
`PreToolUse` hook wrapping the session's commands is what would make
the fence start from outside; the record says so, but the session
did not attempt it.  Hook config is Henri's, which is a reason to
have asked and not a reason to have skipped it.

2. `sh -n` on every script before its first run, not only on tools.
3. Henri reads `2026-08-25-both.md` and says whether the reshaping
   holds: one fence, a dial, and a hook as the first outside caller.
   If it does, the next step is the hook, and it is his to install;
   if it does not, the record says what kills each order and he
   picks.
4. The fence hook: still zero false alarms.
