## What went right

**Delivery was built red-first and the red caught a real bug.**  The
first run answered the whole pull file as one question; the test showed
it before any green, and it was the harness eating `` inside the
heredoc again — fixed by dropping the braces (`"$i"p`).  The mechanism's
own test, not a read-through, is what found it.

**Trying the andon was the point, and it paid.**  Henri asked to "try
andon there"; the try is what turned `silent-cord` from a design worry
into a measurement — the cord is silent on a machine with no sound
server, which is a larger day-one than "red with the row off".  A cord
you never pull is a cord you never learn is cut.

## What went wrong, named as the session's

**The andon question was a paragraph.**  A cord's question should be a
line the person reads at a glance; this one carried the whole demo
command.  The record is for the person, and a wall of text is the noise
the andon's record was built to replace.  Shorter next time; the command
belongs in the recap, not the cord.
