## What the sitting was

`board/keep.md`'s last open half: `node/run.sh`, a launcher that bakes
the node's grant in — `--allow node.py` for code, `--write <state>` for
its state, the write-scoping built earlier today finding its first
caller — and runs it through keep, so running the node is running it
confined and the incantation is gone.  Test red before the launcher
existed, green after; a mutate row for the one break that bites; the
honest limit written down rather than hidden.

## What went right

**Write-scoping got a real caller the same day it was built**, and it
was the honest fit: the node writes only its state, so the state dir is
`--write` and its code is read-only — the minimal grant, not a broad
one.  The two slices composed the way the card's `leash → sandbox →
keep → program` promises.

**The mutation refused to lie, and the refusal was the finding.**  I
expected `--write → --allow` to go red; it went green.  The reason is
real: with no `--write` at all keep leaves writes ungoverned, so the
node writes its state either way.  So confinement of a well-behaved
program is invisible through that program — it behaves the same
confined or not, because confinement shows only on *overreach*.  Rather
than build a probe that makes the node misbehave (a fixture inventing
the overreach it catches — the quota warning in a lab coat), the limit
is named on `board/green.md` and the write boundary is gated where an
overreach is real, at the keep level.  `partial`, spelled out.

**The state dir was kept separate from the code**, so "writable state"
never means "rewritable code" — the one design point that, missed,
would have made the launcher grant the node write over its own `node.py`.

## What went wrong, named as the session's

**My first reasoning about the test's power was wrong**, and only the
mutation corrected it — I had written on the previous card that the
launcher test would detect `--write → --allow`, and it does not.  The
claim was plausible and untested until `tools/mutate.sh` ran it; a
detector's own power is a measurement, not an argument, which is the
whole of the card this work serves.  The card note is written from the
measurement, not the guess.
