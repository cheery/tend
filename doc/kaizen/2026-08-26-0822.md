## What went right

**The ingestion changed exactly one file, and I could say so in one
line.**  The whole worry a person has about a machine reading its own
journal is what it will quietly rewrite; the honest answer was a single
new ledger and zero edits to anything standing.  The one lesson that
recurred three times without a mechanism is one a session may not
promote — writing it into the founding README would be committing the
very error it names — so it went to Henri's Friday review, not into the
tree.  The reading aid found a promotion and correctly refused to make
it.

**Write-scoping was built as a boundary, not a flag.**  `write_bits = 0`
in a copy turns the read-only grant writable and the test goes red;
that is the difference between a feature that exists and one that bites.
And the default was left exactly as six days of the card described, so
nothing already built moved.

**The lamp defect was mine, and it became the card's fourth detector.**
`board/green.md` is about detectors that have only ever passed; this
session made one fail in the live tree — a ledger the lamp could not
tell from a kaizen — and rather than quietly fix it, it went through the
card's method: test red, patch, proof in a copy, a mutate row that
reverts it.  A found defect is worth more carded than patched.
